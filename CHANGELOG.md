# Changelog

## v0.1 (first public beta)
- All in-game text in English: menus, match settings, wrestler select, results and finishing
  moves, circuit mode, belt bets, belt history, belt name entry and the memory card prompts
  (246 messages).
- Wrestlers carry the names of the real wrestlers they parody. Long names are drawn in narrow
  letters made for the patch.
- A hook in the text routine clears leftovers of the longer Japanese text and lines up the English.
- Three patches: English; English with the bosses unlocked; Japanese with the bosses unlocked.
- Kept as they were: the match time (分/秒), the memory card save title and icon, the movies,
  voices and music.
